# Política de Privacidade — AutoFill Defensoria

**Última atualização:** novembro de 2026

## Coleta de dados
Esta extensão não coleta, armazena ou transmite dados pessoais a servidores externos.

## Uso dos dados
Os dados extraídos da aba ativa (sistema Nossa Defensoria) são processados
localmente no navegador do usuário e usados exclusivamente para gerar o
texto de qualificação jurídica.

## Armazenamento
Os dados ficam temporariamente no `chrome.storage.local` do próprio navegador
e podem ser limpos a qualquer momento.
